# Update Goddard from Goddard

Run `goddard update` to install the latest stable release. `goddard update --check` checks availability without installing; both commands support `--json` and work outside a project.

The updater checks GitHub Releases, verifies the archive checksum and package identity, then invokes npm without a shell or lifecycle scripts. It updates the running installation's global prefix, verifies the installed version, and skips installation when already current. Newer versions are not automatically downgraded. Saved tasks, workspace files, handoffs, and account profiles stay in place.

Stop active Goddard runs before updating. Source checkouts and development links need their original update method; they can still use `update --check`. Errors include guidance for a manual update.

## Get the updater

Older releases do not have this command. Install 0.6.0 once with Node.js 24+:

```sh
npm install --global https://github.com/kggayo/goddard/releases/download/v0.6.0/goddard.tgz
goddard --version
```

For future releases:

```sh
goddard update
```

Tests cover version ordering, check-only behavior, unsupported installations, invalid metadata, network errors, size limits, checksum mismatch, archive identity, and npm failures. Package checks on Windows, macOS, and Linux exercise an installed copy updating itself through real npm with a simulated release, preserving saved tasks and files.
