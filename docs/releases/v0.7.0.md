# Shared controls, images, and better terminal input

Goddard 0.7.0 gives Codex and Claude the same permission and image controls, improves composing replies in Windows Terminal, and adds a waiting indicator.

## Changes

- **Shared permissions:** use `--permission-mode default|auto|read-only|bypass` with either agent. Goddard maps the choice to the selected provider's native controls. Existing `--read-only`, `--dangerously-skip-permissions`, and `--claude-permission-mode` inputs remain compatible aliases. Provider enforcement and automatic-review availability still differ.
- **Multiline input:** Ctrl+J or backslash followed by Enter inserts a newline. Shift+Enter and Alt+Enter work when the terminal reports them distinctly. Pasted multiline text remains one editable draft until you press Enter, including Windows CRLF and rapid unmarked pastes.
- **Images:** repeat `--image PATH` / `-i PATH` on `start` or `run`, or use `/image PATH` at the `You` prompt. On native Windows, Alt+V or `/paste` attaches a clipboard image. `/images` lists pending attachments and `/remove-image N` removes one. Submitted images survive account failover, provider switches, and portable handoffs.
- **Waiting indicator:** a rotating spinner shows account checks, connection setup, agent work, and handoff saving. It pauses at input prompts and clears around messages. `--plain`, redirected output, and dumb terminals disable animation; `--no-color` keeps it without colors.
- Updated the usage guide and wiki source with controls, examples, and compatibility details.

## Install or update

Stop active Goddard runs, then update an existing global installation from 0.6.0 or later:

```sh
goddard update
goddard --version
```

For a new installation, an older release, or an explicit version pin, use Node.js 24+ and npm:

```sh
npm install --global https://github.com/kggayo/goddard/releases/download/v0.7.0/goddard.tgz
goddard --version
```

The release includes bundled runtime dependencies and `SHA256SUMS`. Coding-agent CLIs and their sign-in remain separate prerequisites.

## Examples and limits

```sh
goddard start "Fix the layout in this screenshot" --agent claude --image screenshot.png
goddard run TASK_ID --agent codex --permission-mode auto
```

PNG, JPEG, GIF, and WebP attachments are limited to 5 MiB each, 10 distinct images and 20 MiB total per task. Relative image paths resolve from the workspace root. Model support and provider limits still apply. Images are retained in `.goddard/` and exported bundles; pixels are not redacted. Clipboard image paste currently requires native Windows; other platforms can attach saved files.

At the `You` prompt, empty Enter sends pending images without text; with no pending images it saves and exits. `/done`, cancellation, and EOF discard unsent attachments. Image attachments are available at follow-up prompts, not approval or structured-choice prompts.

On terminals without paste markers, pause briefly before pressing Enter after a paste; Enter arriving during the paste burst remains a newline. Shift+Enter depends on terminal key reporting, so use Ctrl+J if it submits instead.

Verification uses the offline provider fixtures, recovery demo, and package installation checks. Provider image/permission behavior was not tested through paid live model calls. The release workflow gates publication on Windows, macOS, and Linux checks.
