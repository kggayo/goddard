# Quiet version and help commands

Fixes [issue #4](https://github.com/kggayo/goddard/issues/4), based on [KeuqS's contribution in PR #7](https://github.com/kggayo/goddard/pull/7).

`goddard --version`, `-v`, `--help`, `-h`, `help`, and the no-argument help path no longer load SQLite. These commands now print their result without Node's experimental SQLite warning.

Database-backed commands still load SQLite when needed. Node warnings are not globally suppressed, so affected Node versions may still print the experimental warning when using task storage or accounts. Task creation, `start`, `run`, and handoffs keep their existing behavior.

## Install or update

Node.js 24+ required:

```sh
npm install --global https://github.com/kggayo/goddard/releases/download/v0.5.1/goddard.tgz
goddard --version
```

Expected version output: `0.5.1`, with no SQLite warning.

Regression tests reject SQLite imports on every lightweight command and check normal output with empty stderr. The installed package is checked through its command shim on Windows, macOS, and Linux, including database-backed task creation and handoffs.
