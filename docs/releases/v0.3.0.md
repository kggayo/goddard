# First public package 🐾

Goddard carries unfinished coding work between Codex and Claude Code sessions. This first packaged release makes it possible to try the CLI without cloning the repository.

## Install

Requires Node.js 24+, Git for Git workspaces, and an installed Codex CLI or Claude Code.

```sh
npm install --global https://github.com/kggayo/goddard/releases/download/v0.3.0/goddard.tgz
goddard --version
goddard doctor
```

One package works on Windows, macOS, and Linux, with runtime dependencies included. `SHA256SUMS` contains the download's checksum. The automatically generated GitHub source archives are for development; use **goddard.tgz** to install the release.

## Ready to try

- Managed Codex and Claude Code sessions with chat, questions, approvals, model selection, and effort settings.
- Saved goals, clarifications, checkpoints, workspace evidence, and portable handoffs.
- Automatic account-profile selection and quota failover within the selected provider.
- An explicit switch between Codex and Claude while retaining the saved handoff.
- Readable terminal output and an offline recovery demo in the source checkout.

This is early software. Checkpoints are best effort and evidence is bounded; Goddard does not transfer private model state or grant extra provider quota. Claude quota visibility depends on emitted events. DeepSeek, Muse, Kimi, Grok, and Gemini are roadmap items, not supported integrations.

CI checks syntax, runs the fixture tests and recovery demo, and installs this exact tarball into a fresh prefix on Windows, macOS, and Linux. Installation checks run offline with an empty npm cache and exercise the actual command, SQLite tasks, notes, workspace capture, and handoff export. CI does not use live provider accounts.

Follow the [getting-started guide](https://github.com/kggayo/goddard/blob/v0.3.0/README.md#take-it-for-a-walk), read the [installation guide](https://github.com/kggayo/goddard/blob/v0.3.0/docs/installing.md), or [report what happened](https://github.com/kggayo/goddard/issues/new?template=bug_report.yml). Small fixes and first contributions are welcome.
