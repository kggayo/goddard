## Goddard's original mascot

`goddard-mascot.png` is an original AI-generated illustration made for this project: a friendly enamel robot puppy guarding a folder of saved work. It is offered under the repository's [MIT license](../../LICENSE), to the extent the project holds rights in it. The [generation brief](mascot-prompt.txt) records the design.

The project name is an affectionate reference to the robot dog from *Jimmy Neutron*. The original television character and its design belong to their respective rights holders. The uploaded reference image of that character is not distributed in this repository, and this project is not affiliated with or endorsed by the show.
