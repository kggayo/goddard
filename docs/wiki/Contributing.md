# Come build with us 🐾

A clearer example, a typo fix, or a useful bug report is a contribution. You don't need an invitation or write access to get started.

## Improve this wiki

The reviewable source for these pages lives in [`docs/wiki/`](https://github.com/kggayo/goddard/tree/main/docs/wiki) in the main repository.

1. Fork [kggayo/goddard](https://github.com/kggayo/goddard).
2. Edit the matching Markdown page under `docs/wiki/`.
3. If adding a page, update `Home.md` and `_Sidebar.md` so readers can find it.
4. Check the commands and links, then open a pull request against `main`.

Maintainers publish accepted changes to this wiki. This gives outside contributors the same review path as code changes, including a visible diff and discussion. You can also [open a documentation issue](https://github.com/kggayo/goddard/issues) if you don't want to edit the page yourself.

## Help with Goddard

- [First pull request guide](https://github.com/kggayo/goddard/blob/main/CONTRIBUTING.md): setup, checks, and repository layout.
- [Good first issues](https://github.com/kggayo/goddard/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22good%20first%20issue%22): small starting points.
- [Discussions](https://github.com/kggayo/goddard/discussions): ideas and usage questions.
- [Roadmap](https://github.com/kggayo/goddard/blob/main/ROADMAP.md): future provider investigations and current scope.

Routine tests use fake providers without live account quota. For documentation changes, verify what you touched; you don't need to buy a subscription.

Please review logs before sharing and keep credentials, private project files, and recovery bundles out of public issues. Report vulnerabilities through the [security policy](https://github.com/kggayo/goddard/blob/main/SECURITY.md).
